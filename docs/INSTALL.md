# CAD2NC 安装与升级

从 [GitHub Releases](https://github.com/s1eke/cad2nc/releases) 下载并运行 `CAD2NC-Setup-2.7.0-x64.exe`，向导会自动判断是首次安装、更新还是重新安装，并显示对应说明。首次安装默认放到当前用户的 `%LOCALAPPDATA%\Programs\CAD2NC`，不需要管理员权限；完成后可从开始菜单或桌面快捷方式启动。桌面快捷方式默认勾选，可在首次安装向导中取消。

安装包已包含 .NET、Windows App SDK 和应用运行资源。使用时不需要联网下载运行库，也不需要另装 Python、CAD 软件或 LibreDWG。请通过正常快捷方式启动，避免“以管理员身份运行”带来的文件拖放权限差异。不会更改 DWG / DXF 的默认打开程序。

程序技术兼容目标为 Windows 10 22H2（build 19045）及更新系统的 x64 环境，推荐使用仍受支持的 Windows 11。独立机器上的实际兼容验收情况以同版本验证记录为准；[微软 .NET 10 支持清单](https://learn.microsoft.com/en-us/dotnet/core/install/windows)与技术最低版本不同。

## 打开图纸

启动直接进入工作台，将一个 DWG / DXF / NC 文件拖入应用窗口即可加载，也可以使用「打开文件」或继续已保存的加工任务。拖到 CAD2NC 桌面快捷方式或程序图标上也会打开文件。使用中的应用会接收新的打开请求；已有任务未保存时先询问保存。外部 NC 在同一工作台只读查看。

顶部将文件信息与主命令合并为 56 DIP 一行，下方为 36 DIP 状态行；「说明 / 设置」位于更多菜单，页面顶部可「返回工作台」。工作台依次提供「打开文件／保存任务／生成刀路／导出 NC」，生成与导出保留各自位置，根据当前状态使用强调色。加工内容变化后生成按钮显示「更新刀路」，失败或已有结果时显示「重新生成」。

轮廓列表提供形状缩略图及选中的加工侧详情，复选框决定是否加工；「加工顺序」只查看有效计划，不能拖拽改序。参数栏默认展开「机床与工件／刀具／切削／深度与分层」，收起「补偿与方向／机床输出与结束动作」。可设置机床、板厚、Z 基准、母板或手动原点、稳定顺序、分层、斜坡和停车动作。深度分层仅在显式开启分层时生效。画布图例可直接开关原图、成品边、刀心、空移和方向；旧结果失效时淡化显示并标注待更新，需重新生成后才能导出、复制或播放。

结果抽屉只占中央区域，左右侧栏保持全高；收起时保留摘要、代码和诊断入口，长内容可打开「大视图」。无警告成功时保持收起，Warning 或 Error 自动进入诊断，Warning 仍可导出 NC。外部 NC 默认打开源码，宽窗口将轨迹与详情并排，窄窗口切换预览与程序详情；无法播放的程序优先显示源码大视图。带来源行的解析提示可直接跳到原文。完整说明见安装目录中的 `使用说明.md`。

首次启动使用宝元 LNC 内置值：板底／垫板面 Z0、17 mm 板厚、母板左下角原点、安全 Z45、最终 Z-0.10 和斜坡下刀。以后使用在设置中明确保存的启动默认配置；打开已保存任务则恢复任务内的完整参数与原点。同一窗口打开另一张 CAD 沿用当前工艺，但清除上一张图的母板与手动原点。

「设置 → 参数配置」提供导入、导出当前参数、保存当前参数为启动默认和恢复所选机床内置值，通过 `.cad2nc.config.json` 文件复用机床、刀具、工艺参数及原点方式，不含本图母板和手动坐标。导入先比较再应用，取消不修改参数；应用或恢复内置值后可撤销，需重新生成刀路。普通任务编辑或恢复内置值不会自动覆盖启动默认，保存启动默认也不会改变其他任务。旧个人配置数据继续保留，但不再提供管理入口。T 与 H 分别表示刀号和刀长补偿号；可选择「H 跟随刀号」，手工修改 H 后保持独立。

「保存任务」用于下次继续编辑，默认写入 Windows 实际「文档」位置下的 `CAD2NC\任务`；「导出 NC」用于输出本次有效生成的加工程序，默认写入 `CAD2NC\NC`。目录在首次写入时创建，已有任务继续保存到原文件。新任务或 NC 重名时可覆盖、另存为或取消。更多菜单提供另存为，自动补齐相应后缀，覆盖确认针对最终路径。「设置 → 文件保存」可分别更改、打开或恢复两个默认目录，变更立即保存，不移动已有文件；临时另存为不改变默认目录。外观主题在设置页即时切换，主题和目录调整不改变任务保存状态及有效 NC。

生成后点击画布下方「播放」可手动查看二维 NC 运动，并暂停、回到起点、拖动进度或选择 `0.25×` 至 `10×` 倍率（默认 `10×`）。播放栏单行显示动作、轮廓、加工层和 NC 行，XYZ 在窗口底部状态栏同步更新；时间为估算，空移采用 `10000 mm/min` 示意速度。编辑加工内容、撤销／重做、重新生成或导入会清空旧播放。二维播放不检查实际夹具碰撞、机床行程或加减速；「说明」另列上机后的核对步骤。详细边界和操作见 [中文使用说明](PORTABLE.md)。

## 升级与卸载

更新前先保存任务并退出 CAD2NC，再运行新版离线安装包。不需要卸载旧版，也不需要联网检查更新。程序仍在运行时会提示先正常退出，不会强制终止尚未保存的工作。

| 向导显示 | 适用情况和操作 |
| --- | --- |
| 安装 CAD2NC | 电脑上没有本安装器的安装记录，按向导完成首次安装。 |
| 更新 CAD2NC | 当前版本低于安装包，向导显示「当前版本 → 更新后版本」，点击「开始更新」。 |
| 此版本已经安装 | 已安装相同版本；程序无法正常使用时，点击「重新安装此版本」补齐程序文件。 |
| 无法读取原版本 | 检测到安装记录但版本信息不可读时，允许重新安装以补齐程序文件。 |
| 电脑上的版本比安装包更新 | 拒绝旧安装包覆盖，请使用相同或更新版本的安装包。 |

更新和重新安装会沿用原程序位置及上次安装时的快捷方式选项，不再重复询问。手工删除过的快捷方式可能按原选项恢复。安装器只管理本安装器在当前用户下的安装记录，不搜索其他用户或搬移便携版目录。

设置、最近任务和个人参数配置保存在 `%LOCALAPPDATA%\CAD2NC\settings-v2.json`，schema 保持 2，升级时保留。新任务及参数文件只写版本 3，并兼容读取版本 1/2；旧文件缺少稳定顺序字段时迁移为开启。打开旧任务不会改写原文件或旧 `.nc`，保存后才升级为 v3。旧设置未配置保存目录时使用默认文档目录。CAD 侧栏已有合法宽度继续沿用，首次或缺少宽度时使用左 240、右 320 DIP。NC 详情宽度独立保存在本机，默认 480 DIP，不覆盖 CAD 侧栏偏好，也不进入任务文件。

旧便携版若使用同一 Windows 用户，安装版也会读取已有设置，并保留原有旧版设置迁移行为。旧设置缺少启动默认字段时采用宝元内置值，旧个人配置数据和旧任务保持原加工语义；这不代表升级删除了原设置。任务重新打开后需重新生成刀路，即可导出有效 NC。

在 Windows“设置 → 应用 → 已安装的应用”中找到 CAD2NC 并卸载。卸载会移除安装文件和本安装器创建的快捷方式，保留用户设置。自己保存的 CAD、任务文件和 NC 文件也会保留。原便携版目录由用户自行保留或清理，不属于安装器管理范围。

安装包未配置产品代码签名证书，Windows 下载保护可能显示未知发布者。源码分发包包含安装脚本、资源和对应应用源码；发布者应将同版本源码包与安装包一同提供。

## 从源码构建安装包

需要 Windows x64、PowerShell 7 与 `global.json` 指定的 .NET SDK。首次准备固定版本的 Inno Setup 编译器：

```powershell
pwsh -File scripts/prepare_inno.ps1
pwsh -File build.ps1
```

准备脚本校验官方安装器固定 SHA-256 和 Authenticode 签名，并使用官方 `/PORTABLE=1` 模式放入 `.tools/inno-setup/7.1.0`，不注册编译器文件关联、快捷方式或系统卸载项。网络受限时可从[官方固定版本](https://github.com/jrsoftware/issrc/releases/tag/is-7_1_0)取得文件，再传入 `-InstallerPath`；离线文件也必须通过相同校验。

主构建脚本执行还原、回归测试、自包含发布和发布 EXE 转换自检，然后生成 `dist/CAD2NC-Setup-2.7.0-x64.exe`、对应 `.sha256` 校验文件和 `dist/CAD2NC-source.zip`。`dist/CAD2NC` 保留完整安装载荷用于验收。版本由 `Directory.Build.props` 中的 `Version` 统一派生；需要额外便携 ZIP 时运行 `pwsh -File build.ps1 -PortableZip`。tag 发布流程见 [开发与发布检查](DEVELOPMENT.md)。

已准备完整且版本匹配的发布载荷后，可单独重新编译安装器：

```powershell
pwsh -File scripts/build_installer.ps1 -PublishDirectory dist/CAD2NC -OutputDirectory dist
```

主脚本与独立脚本均支持 `-InnoSetupCompiler <ISCC.exe>`；替代路径中的编译器仍须是有效官方签名的 7.1.0。常规构建不会自动安装编译工具，也不会将应用安装到用户目录。

`scripts/test_installer_modes.ps1` 使用生产安装脚本中的 Pascal 函数测试版本比较与模式分流，不执行产品安装。`scripts/test_installer.ps1 -InstallerPath <安装包> -StaticOnly` 检查哈希、版本及保护约束；实际安装验证须满足脚本的独立账户、注册表和配置目录隔离要求。逻辑、编译或静态检查不等同于真实安装／更新验收，实际完成情况见 [验证记录](VALIDATION.md)。
