# CAD2NC 2.6.4 加工工作台使用说明

运行 `CAD2NC-Setup-2.6.4-x64.exe` 安装，再从桌面快捷方式或开始菜单启动。安装包会根据电脑上的版本显示「安装」「更新」或「重新安装」，不需要另外寻找更新工具。本版附带运行所需组件，不需要联网下载，也不需要安装 Python、CAD 软件或 LibreDWG。目标平台为 Windows 10 22H2 / Windows 11 x64，实际验证范围见 [验收记录](VALIDATION.md)。安装、升级和卸载见 [安装说明](INSTALL.md)。

可将单个 DWG / DXF / NC 拖到窗口工作区直接加载，或拖到桌面快捷方式启动并加载；已有窗口会被复用，最小化时会恢复。「打开文件」还可继续已保存的加工任务，扩展名不区分大小写。未保存的任务仍先询问保存，当前计算可选择停止后再打开。打开确认或导入过程中再次拖入会提示稍后重试。多文件、文件夹和其它格式不会替换当前内容；损坏图纸显示导入错误，不能导出旧 NC。

如果使用可选便携 ZIP，解压整个文件夹后运行 `CAD2NC.exe`，保留同目录的 DLL 和资源文件。

## 在工作台完成加工任务

顶部将文件信息和主命令合并为 56 DIP 一行，下方为 36 DIP 状态行。按钮依次为「打开文件 / 保存任务 / 生成刀路 / 导出 NC」，当前下一步使用强调色；生成和导出保持各自位置。窗口较窄时，放不下的命令收入更多菜单；撤销、重做、打开任务、最近、另存为、说明和设置也位于该菜单。启动直接进入工作台，未打开文件时在画布区域提供打开文件、继续加工任务和拖放提示。

1. **打开文件**：点击「打开文件」读取 DWG / DXF，或继续已保存的加工任务。一次处理一个文件；打开 NC 会进入只读查看模式。
2. **设置加工**：勾选要加工的轮廓，设置外边／内孔、刀具和工艺参数，点击「生成刀路」（F5）。内容变更后按钮显示「更新刀路」，失败或已有结果时显示「重新生成」。母板候选默认不加工，明确位于零件内部的圆孔自动设为内侧加工，仍可手动修改。点击或高亮轮廓只用于查看，不会改变加工勾选状态。
3. **导出 NC**：生成有效结果后，点击顶部「导出 NC」。中央底部「加工摘要」列出图纸名、刀具、实际层数、加工顺序、刀心范围、原点和保存位置。不需要进入说明页或勾选任何确认项。稳定加工与装夹相关的 Warning 不阻止导出；参数错误、没有加工对象、生成失败或结果过期时导出按钮禁用，并说明原因。
4. **打印标签**：生成有效刀路后点击「打印标签」，按母板打印横向热敏标签。多母板默认打印全部，也可在结果区选中一块后只打印当前板；标签用于加工后分拣，突出订单标识、板号（第几块/共几块）、板材尺寸、黑白板形示意和离线二维码，轮廓图内的黑点表示定位点。打印机驱动需配置对应纸张。

打开说明、设置或切换工作区视图会保留画布、选择和编辑状态。后台计算结束时继续停留在当前页。拖入图纸、切换页面或播放不会自动导出 NC。生成端支持宝元 LNC 和通用 Fanuc 配置；软件验证与目标机床验证的范围分别记录在验收文档中。

圆孔自动识别用于新打开的 DWG / DXF：原图中的完整圆在变换后仍为圆，且严格位于一个非母板零件轮廓内、与零件边界不接触、内部没有其它轮廓时，默认选中并设为内侧加工。直接位于母板内的独立圆形零件仍默认外侧；相接、多重嵌套、椭圆及多段线拼成的近似圆保留手动指定。识别结果会在诊断中说明。打开已保存任务时优先恢复任务中的加工侧和勾选状态，不覆盖原有选择；重新打开源 CAD 则采用自动识别的默认值。

窗口宽度 ≥1200 DIP 时采用左侧轮廓、中央画布与播放、右侧参数三栏布局；900–1199 DIP 时显示画布与上次使用的一个侧栏；不足 900 DIP 时通过唯一选中的「预览 / 轮廓 / 参数 / 结果」切换。首次默认侧栏宽度为左 240、右 320 DIP，已有合法宽度继续沿用。侧栏可收起和调整宽度，也可从画布工具栏重新打开；窗口缩小时会按可用空间调整显示宽度。

常规结果抽屉只占中央区域，展开不压缩左右侧栏高度。收起时保留「加工摘要／NC 代码／诊断」入口，展开默认占中央可用区域的 28%，可在 22%–55% 之间调整；长源码或诊断可点「大视图」，再点「返回预览」恢复。无警告的成功结果和仅 Information 信息保持收起，Warning 或 Error 自动打开诊断。诊断中的「定位关联轮廓」会显示相关图形。

轮廓列表显示真实形状缩略图。行底色表示当前选中，复选框表示参与加工，列表同时显示选中数与加工数。选中详情提供内／外侧示意和批量修改；多选不同加工侧时显示混合状态。搜索和图层筛选继续可用，批量菜单明确作用于当前显示或当前选中项。「加工顺序」只查看有效计划的顺序，不能拖拽改序；结果失效时返回「全部」。

同一份 CAD 含有多个独立母板时，生成结果会自动进入多母板模式并合并预览。点击画布中的母板外框或加工摘要中的母板项，可加载该板独立 NC、查看代码并播放轨迹；点击「查看全部母板」返回全图静态预览。点击顶部「导出多个 NC」或更多菜单中的批量导出，会按母板分组，在默认 NC 目录生成带序号的多个 `.nc` 文件；每块板使用自己的母板左下角原点并独立校验。同一母板内的多个零件仍合并为一个程序。母板重叠、轮廓跨板或未归属时会拒绝整批写出。

滚轮以鼠标位置缩放，中键拖动画布。画布边缘的「原图／成品边／刀心／空移／方向」图例可以直接开关对应显示层。显示层开关、定位选中项、窗口大小变化均不改变加工参数。

## 机床与参数说明

从顶部更多菜单打开「说明」，未打开文件也能阅读。纵向卡片集中介绍字段含义、补偿、深度分层、安全高度、原点单位，以及参数与实际机床、刀具及装夹的关系；有当前加工任务时附带实际参数，可定位相应字段修改，也可使用「返回工作台」。

该页面仅供阅读参考，没有人工确认复选框、核对进度或保存门槛。工作台中的软件诊断仍会指出参数无效、轮廓关系冲突和刀路生成失败等实际错误；单位未声明、忽略图形等警告持续显示，不需要手动确认才能生成或输出。

| 说明主题 | 与机床及加工的关系 |
| --- | --- |
| 图纸与尺寸 | 对照原图核对形状、数量与关键尺寸，确认没有遗漏或多余轮廓。 |
| 图纸单位（未声明时出现） | 用原图中的已知尺寸核实当前毫米解释；不一致时回到 CAD 修正单位并重新导入。 |
| 加工对象 | 逐一核对加工勾选和外边／内孔，确认母板边框等不需要加工的轮廓没有被误选。 |
| 刀号与刀长补偿 | 刀号 T 调用刀具，H 引用机床刀长补偿表，两者可以不同；应对应实际装刀和已测量的刀长。 |
| 刀径与工艺 | 刀径用于计算刀心路线；转速、主轴方向、切削和下刀进给需结合刀具、材料与控制器能力。 |
| 深度与高度 | 核对工件 Z0、材料厚度、最终深度、每层下刀量和安全高度；安全高度须结合压板及夹具确认。 |
| 原点与刀路 | 对照 G54 标记检查原点、刀心范围、走刀顺序、方向和空移连线，可结合画布下方的二维播放。 |
| 控制器适配 | 宝元默认单独 T 刀号、G43 H、停车点与 M17/M30，现场格式不输出 G40；通用旧版使用 T+M06 并保留 G40。实际换刀和 M17 动作不在二维预览中模拟。 |

图纸读取提示、未闭合边线和其它诊断保留在工作台的「加工结果」，不用进入说明页即可查看。可定位有关图形，原始技术信息用于排查。

参数、加工选择或加工侧发生修改，以及导入参数、恢复默认、撤销／重做、重新生成，都会使旧结果失效。画布保留的旧成品边、刀路和方向标记会淡化，显示「上次结果 · 待更新」；旧结果不能导出、复制或播放，需重新生成。原图和当前选中轮廓仍可查看。缩放、平移、显示层和页面切换不会使结果失效。

现场核对可按此顺序进行：核对文件和控制器支持情况；核对实际装刀、刀长补偿、装夹、G54 与安全高度；再按现场规程进行控制器仿真和首次空跑。二维播放不检查实际夹具碰撞、机床行程或加减速。

## 加工参数与设置

**首次启动采用宝元 LNC 内置参数；以后采用你明确保存的启动默认配置。** 普通任务内修改不会自动覆盖启动默认，在设置中点击「保存当前参数为启动默认」才保存。打开已保存任务恢复其中的完整参数和原点设置；同窗打开另一张 CAD 沿用当前工艺参数，但清除上一张图的母板和手动原点。打开外部 NC 不会将解析参数应用到加工配置。

宝元内置值：板底／垫板上表面 Z0、板厚 17 mm、`T2 / H2`、6 mm 直刀、`M03 S18000`、切削进给 `10000 mm/min`、到板面进给 `8000 mm/min`、斜下刀进给 `3000 mm/min`、最终 `Z-0.10`、安全 `Z45`、封边吃料 `1 mm`，逆时针。默认启用「优先保持零件稳定」，按内孔、普通外轮廓、母板/外框候选排序，并在每个深度层依次加工全部路线。斜坡沿补偿后的闭环走 80 mm，到目标层后完整再走一圈；短轮廓跨过闭合点继续斜坡，保证入口段也加工到底。本次仅生成闭合轮廓切割，不包含钻孔、开槽、自动排版或自动翻面。

按默认 17 mm 板厚、板底 Z0 计算：板面为 Z17，最终 Z-0.10 表示切穿再下切 0.10 mm，安全 Z45 高出板面 28 mm。深度字段始终是绝对工件坐标，切入量等于板面 Z 减最终 Z。修改板厚后需检查安全高度；安全 Z 必须高于板面，启用结束停车时停车 Z 不低于安全 Z。分层开关默认关闭，留皮为 0 时只下到一次最终深度；开启分层后才按每层最多 3 mm 生成中间深度。可切换垂直下刀，斜坡长度和进给也可调整。

稳定模式会在保持闭环方向和长度的前提下，从闭环顶点及有效线段中点中选择下刀点，并参考其它成品边和可信母板边界。斜坡同时考虑起点和走完斜坡长度后的断开位置。没有可靠参考几何时保留传统左下角起点并给出 Warning。明确指定的母板优先；否则只信任唯一母板候选，不用总包围框或手动原点假装板边。

该策略只降低零件过早切断后移动的风险，不模拟材料、真空、压板、夹具、桥位或底部薄皮，也不保证现场固定。无论是否启用，都必须根据板材与设备核对可靠装夹；这些风险提示不替代控制器仿真和空跑。

「机床与工件」中选择机床配置、板厚、Z 基准与 XY 原点。切换机床会应用所选机床的完整内置参数，可撤销。宝元默认母板左下角；唯一明确的轴向矩形母板候选自动选定，多候选或未找到时需指定母板，或切换手动 CAD 原点。母板不参与默认切割，勾选其他轮廓不会移动母板原点。手动原点输入的是图纸中对应 G54 X0/Y0 的 CAD 坐标，必须完整填写 X 和 Y；只填写一个坐标时不能生成刀路。

机床输出参数可调整单独 T／T+M06、程序外框、结束停车和 M17。宝元默认不用 `%` / O 外框、不输出 M06；结束先停主轴，抬至 Z50，再移至 X200 Y2600，期间保留刀长补偿，最后 M17/M30。M17 按用户提供的机床样例保留，实际动作与耗时未模拟。所有定位先抬 Z，再移 XY。

「通用 Fanuc · 旧版」保留原来板面 Z0、Z5 安全高度、刀心包围框左下角、T+M06、`%` / O 程序号和无停车点的控制器设置；内置 profile 仍默认启用稳定顺序。关闭「优先保持零件稳定」可对照原先逐轮廓完成全部深度的顺序。在此配置且板面为 Z0 时，Z-0.10 才表示切入 0.10 mm。

参数栏的常用参数区突出「留皮厚度」，其余「机床与工件／刀具／切削／深度与分层／补偿与方向／机床输出与结束动作」分组默认收起。后者提供换刀、程序外框、停车开关与 XYZ、末尾 M17 设置。高度示意和摘要显示板面、最终 Z、切入量和实际有效层数。留皮为 0 时，单层下切量仅在显式开启分层时参与计算；正值留皮采用留皮和最终切深两次加工。参数错误会展开对应分组并定位字段；参数导入导出、保存启动默认与恢复机床内置值放在设置页。

- **H 跟随刀号**：勾选时，修改 T 会同步修改 H。手工修改 H 会关闭跟随；重新勾选会立即把 H 设为当前 T。打开任务或应用配置保留其中的 T／H；两者不同时保持独立。
- **导出当前参数**：生成版本 3 的 `.cad2nc.config.json`，包含机床、刀具、工艺及原点方式，不带图纸、母板引用、手动 CAD 原点、加工选择或 NC。仍可导入版本 1/2；缺少稳定顺序字段时迁移为开启。
- **导入参数**：选择配置文件后，先查看当前值与导入值的对照，变化项会标出；点击「应用到当前任务」后才修改参数，取消不改变任务。应用可撤销，旧刀路失效，需要重新生成。
- **恢复所选机床内置值**：恢复该机床内置参数，可撤销；需要重新生成。若想以后启动也使用这些值，再保存为启动默认。
- **保存当前参数为启动默认**：保存当前有效机床和工艺参数，影响以后启动；不保存本图母板或手动原点，不改变其他已保存任务。

导入、导出参数时，文件选择器或差异对话框在设置页上打开，取消或完成后继续停留在设置页并保留滚动位置；取消不修改参数。恢复机床内置值和保存启动默认直接执行。失败信息在设置页显示。旧个人配置数据继续兼容读取和保留，不再提供管理界面，也不自动应用。

从顶部更多菜单打开「设置」。页面采用整页滚动卡片，内容相对整个页面居中，最大宽度 960 DIP，依次为「外观 / 文件保存 / 参数配置 / 关于」，顶部可「返回工作台」。「外观」可选择跟随系统、浅色或深色，即时生效，画布始终保持深色。主题是全局偏好，切换不会令加工任务变为未保存，也不会清空有效 NC；打开旧任务仍使用当前软件主题。主题保存失败时，选择项和实际外观一起恢复。

参数配置文件与加工任务文件不能混用。配置缺少必要参数、包含不支持的字段、采用不支持的版本、数值无效或文件超过 256 KB 时会拒绝导入，当前参数保持原样。导出会自动补齐 `.cad2nc.config.json`，同名时先确认最终保存位置。工艺参数存在输入错误时不能保存启动默认或导出配置；本图母板或手动原点尚未确定，不妨碍保存这些可复用参数。

## 三种保存分别用于什么

| 操作 | 保存内容 | 用途 |
| --- | --- | --- |
| 保存任务 | 图纸引用、完整参数、母板与手动原点、轮廓选择和兼容用视图字段，文件为 `.cad2nc.json` | 下次继续编辑当前加工任务。 |
| 设置 → 导出当前参数 | 机床、刀具、工艺参数与原点方式，文件为 `.cad2nc.config.json` | 复用参数，或传给另一台电脑。 |
| 导出 NC | 本次有效生成的 `.nc` 程序 | 带到机床进行现场验证与加工。 |

默认目录采用 Windows 实际「文档」位置，包括已重定向到其它磁盘或云盘的文档文件夹；应用在首次写入时自动创建所需子目录：

| 操作 | 默认位置 |
| --- | --- |
| 首次「保存任务」 | `文档\CAD2NC\任务\图纸名.cad2nc.json` |
| 「导出 NC」 | `文档\CAD2NC\NC\图纸名.nc` |

点击「保存任务」或「导出 NC」直接使用对应目录。已有任务继续保存到原任务文件，无需每次选择位置；新任务或 NC 遇到同名文件时，选择「覆盖」「另存为…」或「取消」。更多菜单中的「加工任务另存为…」「机床程序另存为…」可指定其他位置；最近文件、撤销与重做也放在更多菜单中。参数配置导出每次通过对话框选择位置。

任务另存为对话框筛选 `.json` 文件，建议文件名带完整 `.cad2nc.json` 后缀。程序在返回后统一补齐任务后缀，避免重复追加，并针对最终写入路径确认覆盖；确认时请核对完整路径。保存成功后显示完整位置，可点击「打开文件夹」。目录无法写入或保存失败时，当前任务仍保留，可更换位置后重试。输出使用原子写入，并禁止覆盖源 CAD。

保存任务会生成版本 3 的 `.cad2nc.json`，不包含可直接保存的有效 NC。再次打开时重新读取 CAD，恢复任务参数、原点和轮廓选择，但沿用本机最后的侧栏、结果高度和显示层布局，视口自动适应新图；需要重新生成刀路。打开版本 1/2 任务会迁移为默认开启稳定顺序，显示迁移提示并标记为未保存；原文件及同目录旧 `.nc` 不会自动改写，保存任务后才写版本 3。如果源文件被移动可重新定位，如果内容变化会重置选择与原点并提示核对。任务文件不会嵌入 CAD，传给另一台电脑时应同时带上源图纸。

「设置 → 文件保存」分别显示默认任务文件夹和默认 NC 文件夹的完整路径，提供更改、打开及恢复默认。目录更改立即保存；恢复默认后使用上表位置。已有文件不会随设置移动，已有任务仍保存回自身路径，临时另存为也不会改变两个默认目录。更改目录、切换主题或收起结果区都不修改加工内容，也不影响已有有效 NC。

## 二维 NC 播放

生成成功后，画布下方的播放控件准备就绪，点击「播放」才开始，无需先导出文件。播放依据本次生成的实际 NC 文本，覆盖空移、斜向或垂直下刀、切削、逐层或逐轮廓顺序、抬刀及结束停车；从第一个 XYZ 坐标完整的位置开始，不虚构机床初始位置。画布将 NC 坐标还原到当前 G54 原点对应的 CAD 位置。静态空移连线也来自实际 NC，包含斜坡结束位置到下一次下刀点的返回和最终停车；「适应全图」包含停车位置。

- 「播放/暂停」控制运动，「回到起点」暂停并归零。结束时停在末尾，再次点击「播放」从头开始。
- 拖动进度滑块可定位，拖动时暂停，松开后保持暂停。
- 播放倍率为 `0.25×、0.5×、1×、2×、5×、10×`，默认为 `10×`。
- 移动刀具按当前刀径绘制，显示已走路径和当前段；绿色表示切削，橙色表示空移。已走路径遵循刀心路线与空移图层开关。
- 画布下方单行显示运动类型、实际刀次/总刀次、当前路径、加工层、NC 行及估算进度时间，XYZ 显示在窗口底部状态栏；NC 预览中的当前行单独高亮，不改变已有文本选择。没有 PATH/PASS 注释的旧 NC 不虚构刀次元数据。

播放进给使用 NC 中的 F 值，空移按 `10000 mm/min` 示意速度计算，界面时间为估算，不代表机床实际加工节拍。下刀和抬刀在二维画布中的 XY 位置可能保持不动，此时通过 Z 坐标和运动类型判断。

缩放、平移及查看轮廓不打断播放。编辑参数、原点、导入参数、恢复机床内置值、改变加工选择、撤销／重做、重新生成或切换文件时立即清空旧播放，生成新的结果后再播放。保存或复制有效生成的 NC 不需要额外工艺确认；保存时遇到同名文件仍需选择覆盖、另存或取消。

二维播放不模拟 M17、换刀内部动作、三维材料切除、机床偏置表、实际夹具碰撞、行程或加减速。正式加工仍须执行目标控制器仿真及空跑验证。

## 打开已有 NC 文件

通过「打开文件」、拖放到窗口或启动文件参数打开 `.nc`，扩展名不区分大小写。NC 文件进入只读阅读模式，默认显示「NC 代码」。宽度 ≥900 DIP 时，画布与程序详情并排，详情可切换「程序参数／NC 代码／解析提示／加工摘要」；「大视图」放大阅读区域，「返回预览」恢复并排，「查看预览」收起详情。不足 900 DIP 时通过「预览／程序详情」切换。无法播放的程序优先显示源码大视图。

拖动画布与详情之间的分隔线可调整 NC 详情宽度，默认 480 DIP，按窗口可用空间显示。本机记录的 NC 宽度独立于 CAD 的轮廓栏和参数栏，切回 CAD 时继续沿用原有 CAD 布局。此模式隐藏加工参数编辑、轮廓选择、生成刀路、保存任务和生成程序导出，设置页的参数导入、导出、恢复机床内置值和保存启动默认均禁用。

播放、暂停、倍率、进度定位及源码当前行高亮与生成结果相同，也可「复制全部」复制原文。可播放程序中点击代码行会暂停并定位到该行或其后第一个运动；带来源行的解析提示提供「定位源码行」，跳到对应原文，没有来源行的提示不提供跳转。源码、播放行和轨迹共用同一播放位置。

程序参数显示实际出现的程序号、T／H、S／F、主轴方向、单位与坐标模式，多个值按出现情况列出并附来源行。XYZ 范围仅在可计算时显示；刀径、材料、留量和实际安全高度无法确定时显示「未提供」。外部 NC 不使用软件默认加工值，未知刀径只显示位置标记。初始位置不假定为零，从明确建立的位置开始绘制；未提供 Z 时显示「Z 未指定」。

| 支持项 | 解释方式 |
| --- | --- |
| G0／G1 | 空移与直线切削，继承模态位置和进给。 |
| G17 下的 G2／G3 | XY 圆弧，支持 I／J 圆心、正负 R、圆心形式整圆及带 Z 变化的螺旋。 |
| G20／G21 | 英寸或毫米输入，预览尺寸统一换算为毫米。 |
| G90／G91 | 终点使用绝对或相对坐标。 |
| G90.1／G91.1 | 圆心独立使用绝对或相对坐标，不随终点坐标模式切换。 |
| G94 | 每分钟进给。 |
| 单一 G54–G59 | 显示一个工件坐标系内的编程轨迹，不套用实际机床偏置表。 |

程序未声明时，默认按毫米、XY 平面、绝对终点、相对圆心和每分钟进给解释，解析提示会列出这些假设。圆弧语义参考 [LinuxCNC 官方 G-code 文档](https://linuxcnc.org/docs/html/gcode/g-code.html)；各机床控制器的支持范围仍以其说明书为准。

外部程序中的 `G91 G28 Z0` 等回参考点指令，仅接受 G91 模式、显式指定轴且位移全为零的形式；不绘制回零运动或计算其耗时，相关轴直到后续绝对坐标重新建立位置前保持未知。末尾独立 `M17` 仅在后面紧接独立 `M2/M30` 结束时接受，可有行号、注释和空行；保留原文，提示其功能由控制器定义，未模拟实际动作。

宏、子程序、固定循环、其它圆弧平面、刀径补偿、机床坐标移动或运动中切换工件坐标系等超出范围时，保留原文和可识别参数，提示具体问题行并禁用整份轨迹播放。不能解析的运动不会被擅自画成直线。

读取和解析在后台运行，可取消。外部 NC 上限为 **32 MiB、100 万行和 100 万运动块**，超限明确提示，不把截取片段作为完整程序。读取失败时保留此前打开的内容；解析失败时仍可查看已读取的原文。CAD 与 NC 切换继续遵循未保存任务提示。

## 设置与命令行

导入参数、恢复默认、批量改轮廓和参数编辑可撤销／重做；导入另一份图纸会清空撤销历史。

设置、启动默认、最近任务及旧个人配置存于 `%LOCALAPPDATA%\CAD2NC\settings-v2.json`，该设置文件仍为 schema 2。缺少稳定顺序字段时默认开启，显式关闭会原样保存；旧的退出参数不自动成为启动默认。新任务与参数配置只写版本 3，版本 1/2 均可读取并迁移稳定顺序。已有侧栏宽度、目录和最近记录继续保留。

隔离测试或便携部署可在启动进程中设置 `CAD2NC_SETTINGS_DIRECTORY` 为独立配置文件夹的完整路径；该目录保存 `settings-v2.json`，不会读取正常用户的旧配置。未设置时使用上述默认位置。任务与 NC 的输出目录仍在应用设置中分别配置。

封边吃料保持旧版含义：外侧零件成品边内缩 1 mm，内侧孔成品边外扩 1 mm。刀径补偿由软件预先计算；宝元 LNC 现场格式不输出 G40，通用 Fanuc 旧版保留 G40，任何模式都不能再叠加 G41/G42。G54 使用当前所选原点方式，宝元默认指定母板左下角，补偿产生的负 X/Y 保留。

命令行默认使用宝元内置值，要求唯一明确的矩形母板，不读取本机启动默认。支持 `--config 参数文件` 或 `--profile lnc|legacy`（二者互斥），以及 `--origin sheet|manual|toolpath`。手动原点需同时提供 `--origin-x`、`--origin-y`；母板可用 `--sheet-contour C0001` 指定。原点选项覆盖配置文件中的原点方式，不更改文件。

`--include-outer` 可把其他母板候选加入加工选择，但在 `sheet` 原点模式下，作为原点基准的指定母板始终从 CLI 加工选择中排除。该开关不能使指定母板参与切割。

需要把一份图纸中的多块独立母板分别输出时，加入 `--split-boards`。此模式按母板分组，每块板生成一个带序号的 NC；`--output` 指向输出目录（传入 `.nc` 路径时使用其所在目录）。该模式不能与 `--sheet-contour` 或 `--origin manual` 同时使用。

```powershell
$process = Start-Process -FilePath .\CAD2NC.exe -ArgumentList '--convert "D:\图纸\板件.dwg" --output "D:\加工\板件.nc" --summary "D:\加工\摘要.json" --accept-import-diagnostics' -WindowStyle Hidden -Wait -PassThru
$process.ExitCode
```

没有母板的图纸可明确指定手动原点，例如：

```powershell
$process = Start-Process -FilePath .\CAD2NC.exe -ArgumentList '--convert "D:\图纸\零件.dxf" --output "D:\加工\零件.nc" --summary "D:\加工\零件摘要.json" --origin manual --origin-x 1000 --origin-y 2000 --accept-import-diagnostics' -WindowStyle Hidden -Wait -PassThru
$process.ExitCode
```

复用从设置页导出的参数时使用 `--config "D:\工艺\宝元.cad2nc.config.json"`；参数文件不含本图母板和手动坐标，仍需按其原点方式自动识别母板或在命令行指定。`--profile legacy` 只切换机床 profile；顺序由配置中的 `prioritizePartStability` 控制。正值 `leaveSkin` 生成留皮和最终切深两次加工；留皮为 0 时，`layeredCutting` 决定按最大层深分层或只生成一次最终深度。CLI 摘要保留 `prioritize_part_stability`、`cut_order`、`automatic_safety_layering`（现始终为 false）和实际 `depth_passes`；参数或原点错误时不写入 NC。

只有核对过图纸诊断才使用 `--accept-import-diagnostics`，旧名 `--accept-converter-diagnostics` 仍为兼容别名。无单位图纸需明确确认后使用 `--assume-mm`。Windows 图形程序默认不向终端显示输出，自动化应检查退出码和摘要文件。
