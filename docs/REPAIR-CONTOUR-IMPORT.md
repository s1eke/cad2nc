# 母板识别与重复轮廓修复验证

2026-09-14

修复逐块标准母板识别，并在轮廓编号前合并同图层重复提取的闭环。几何比较使用 0.0000001 mm 精度的临时副本，保留轮廓的实际加工坐标不变。普通内外环共享边界的精确去重不额外提示；非精确重复合并通过 `geometry.duplicate_contour` 提示图层、保留编号和合并数量。跨图层重复、交叉线及真实加工间隙检查继续生效。

- Release 测试：613 项通过，无失败、无跳过。
- 覆盖不同顶点数量、方向、浮点噪声、大坐标、真实小差异、内孔、跨图层冲突、取消和比较预算。
- 覆盖两块母板分别包含两个与一个零件、标准与非标准母板并存、嵌套标准矩形不误识别。
- 工作台会话回归覆盖按母板选择播放、批量导出、保存重开，以及源文件哈希不变但去重导致轮廓变化时的旧任务重置。
- WinUI 应用 Release 自包含发布成功，输出目录为 `dist/CAD2NC-contour-fix`。
