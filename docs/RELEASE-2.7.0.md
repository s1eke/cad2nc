# CAD2NC 2.7.0 更新说明

新增圆孔自动内侧加工：新打开 DWG / DXF 时，明确位于零件内部的完整圆孔默认选中并设为内侧加工，无需逐个手动修改。独立圆形零件保持外侧；相接、复杂嵌套、椭圆和多段线近似圆保留手动指定，识别结果在诊断中说明。已有加工任务继续恢复保存的加工侧和勾选状态；重新打开源 CAD 可应用新默认值。原始图纸不会被修改。

统一版本管理：以 `Directory.Build.props` 的 `Version` 为唯一来源，程序集和 Windows 应用清单自动派生为 `2.7.0.0`，安装器、应用及 CLI 摘要使用同一版本。兼容修复递增修订号，兼容功能递增次版本，不兼容变更递增主版本；本次新增功能使用 `2.7.0`。

完善 tag 自动发布：推送 `v2.7.0` 后，GitHub Actions 在构建、测试、示例复现和依赖审计通过后发布 Release，提供 `CAD2NC-Setup-2.7.0-x64.exe`、对应源码 ZIP 及 SHA-256 校验文件。公开前核对 tag 对应的提交，附件先上传草稿，失败可重跑；已经公开的版本保留原下载文件，后续修正发布新版本。发布规则见 [开发与发布检查](https://github.com/s1eke/cad2nc/blob/v2.7.0/docs/DEVELOPMENT.md)。

升级保留设置和已有任务中的加工选择。任务重新打开后需重新生成刀路；如希望已有图纸使用圆孔自动识别，请重新打开源 DWG / DXF。软件验证与独立机器、实际安装和机床验证的完成范围见 [验证记录](https://github.com/s1eke/cad2nc/blob/v2.7.0/docs/VALIDATION.md)。
