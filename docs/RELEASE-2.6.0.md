# CAD2NC 2.6.0 更新说明

本版为当前宝元 LNC 木工开料机增加可配置的闭合轮廓切割输出，并默认采用稳定加工顺序与安全下刀点。首次启动使用「宝元 LNC · 当前木工开料机」，并保留「通用 Fanuc · 旧版」。本版不生成钻孔、开槽、自动排版或正反面坐标转换；每次加工一面，分别导出。

## 宝元内置工艺

- 板底／垫板上表面 Z0，板厚 17 mm；T2 / H2、直径 6 mm，封边吃料 1 mm。
- 主轴顺时针 18000 rpm、切削进给 10000 mm/min；最终 Z−0.10，安全 Z45。
- 默认沿补偿后的闭合刀心路线斜向下刀 80 mm；移至板面进给 8000、斜坡进给 3000 mm/min。短轮廓可继续绕行，到目标 Z 后完整走一圈。
- 默认启用「优先保持零件稳定」，按内孔、普通外轮廓、母板/外框候选排序；同一深度层遍历全部轮廓。即使手动分层关闭，也自动按每层最多 3 mm 使用 Z14、11、8、5、2、−0.10，不改写保存的分层开关。
- 单独输出 T 刀号；结束停主轴、抬至 Z50、移至 X200 Y2600，再输出 M17 / M30。M17 按这台机床样例保留，其实际功能与换刀内部动作不在播放中模拟。

这些参数均可修改。80 mm 斜坡长度是样例对应的默认工艺参数，不是机床固定要求。

## 原点与保存

默认使用指定母板左下角。唯一明确的轴向矩形母板候选自动选定；不明确时需要指定母板或完整填写手动 CAD 原点 X/Y。母板默认不加工，原点不随加工勾选改变，补偿产生的负 X/Y 保留。也可选用旧版刀心包围框左下角原点。

设置页提供「保存当前参数为启动默认」和「恢复所选机床内置值」。当前任务的普通编辑不会自动覆盖启动默认，也不会修改其他任务。打开另一张 CAD 延续当前工艺，清除上一张图的母板和手动原点；重开加工任务使用该任务的参数快照。

参数文件和任务文件升级为版本 3，只写 v3 并继续读取 v1/v2。旧文件缺少稳定顺序字段时迁移为开启；打开旧任务会显示迁移提示并标记为未保存，原任务和旧 `.nc` 不会自动改写。`settings-v2.json` 保持 schema 2，显式关闭值可往返保存。母板引用和手动 CAD 原点仅随任务保存，不写入参数文件或启动默认。配置变更支持撤销、重做，并使旧生成结果失效。

## 校验与播放

板厚、Z 基准、最终 Z、安全 Z 和停车 Z 共同校验；无效高度定位到具体参数。生成前检查闭环、重复点、0.001 mm 舍入退化及完整运动块预算，任何选中轮廓失败均不会输出部分 NC。闭环顶点和有效线段中点参与确定性安全下刀点选择；斜坡同时评估入口及走完斜坡长度后的断开位置。无可靠参考几何时保留传统左下角入口并提示。

生成程序使用严格解析入口校验，预览、播放和实际导出使用同一份通过校验的程序。播放与静态空移预览包含斜坡、分层返回及结束停车，并显示实际刀次、路径和层次。

稳定顺序只降低零件切断后移动的风险，不模拟材料、真空、压板、夹具、桥位或底部薄皮，也不保证现场固定。相关 Warning 不阻止导出；现场仍必须核对可靠装夹、材料状态、控制器仿真和空跑。

CLI 新增 `--config`、`--profile lnc|legacy`、`--origin sheet|manual|toolpath`、`--sheet-contour`、`--origin-x` 和 `--origin-y`。详细用法见 [使用说明](PORTABLE.md)，软件验证和仍需现场验证的项目见 [验收记录](VALIDATION.md)。
