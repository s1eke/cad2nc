# CAD2NC 2.7.0 · WinUI 3 加工工作台

中文 Windows 加工工作台：直接读取 DWG / DXF，识别闭合轮廓，配置工艺，预览成品边和刀心路线，生成可配置的宝元 LNC / 通用 Fanuc NC；也可打开已有 NC 查看程序参数、源码与二维轨迹。

使用 **C# / .NET 10 / WinUI 3**，通过 **ACadSharp 3.7.1** 直接读取 CAD，使用 NetTopologySuite 处理几何、Win2D 绘制预览、CommunityToolkit.Mvvm 管理应用状态。正式发布包不依赖 Python 和 LibreDWG。

## 启动与操作

在本仓库的 [Releases](https://github.com/s1eke/cad2nc/releases) 页面下载 `CAD2NC-Setup-2.7.0-x64.exe` 后运行，按中文向导安装，再从桌面快捷方式或开始菜单启动。安装包会自动区分首次安装、更新和同版本重新安装，显示对应说明；发现电脑上的版本更新时拒绝覆盖。默认安装到 `%LOCALAPPDATA%\Programs\CAD2NC`，仅供当前用户使用，无需管理员权限，运行依赖已经附带。详见 [安装、升级与卸载](docs/INSTALL.md)。

将单个 **DWG / DXF / NC 拖到窗口工作区**即可加载；也可拖到桌面图标，应用会启动或切回已有窗口打开文件。打开文件入口还支持已保存的加工任务。扩展名不区分大小写。已有任务未保存时会先提示保存。一次打开一个文件，连续打开时请等待当前打开流程完成；拖放不会自动生成刀路或导出 NC。

目标系统：Windows 10 22H2 / Windows 11 x64。同版本构建、界面和独立机器上的实际验证范围以 [验收记录](docs/VALIDATION.md) 为准。

1. **打开文件**：打开 DWG / DXF，或继续已保存的加工任务。打开 NC 则进入只读查看模式。
2. **设置加工**：勾选要加工的轮廓，设置外边／内孔、刀具和工艺参数，点击「生成刀路」。内容修改后按钮会显示「更新刀路」，生成失败或已有有效结果时显示「重新生成」。母板候选默认不加工；明确位于零件内部的圆孔自动设为内侧加工，仍可手动修改。
3. **导出 NC**：生成有效结果后，顶部「导出 NC」按钮使用强调色，生成与导出的位置保持不变。默认写入 Windows「文档」下的 `CAD2NC\NC`，也可通过更多菜单另存到指定位置。输出为 ASCII / CRLF。
4. **打印母板标签**：生成有效结果后点击「打印标签」。单板打印 1 张，多母板默认全部打印，也可只打印结果区当前母板。标签面向加工后的分拣，使用黑白热敏布局突出订单标识、板号（第几块/共几块）、板材尺寸、板形示意和离线二维码；轮廓图内的黑点表示定位点。打印机驱动需预先配置对应标签纸规格。

[完整中文使用说明](docs/PORTABLE.md) 包含机床与工件设置、启动默认配置、任务保存、参数导入导出、外部 NC 查看和命令行用法。2.7.0 默认针对当前宝元木工开料机；仅适配闭合轮廓切割，不含钻孔、开槽、排版或自动翻面。新增圆孔自动内侧加工及发布改进见 [2.7.0 更新说明](docs/RELEASE-2.7.0.md)。

## 工作台

- 顶部：文件信息与主命令合并为 56 DIP 一行，下方为 36 DIP 状态行。按钮依次为「打开文件 / 保存任务 / 生成刀路 / 导出 NC / 打印标签」，当前下一步使用强调色；窄窗口将放不下的命令收入更多菜单。撤销、重做、打开任务、最近、另存为、说明和设置也位于更多菜单。
- 轮廓侧栏：真实轮廓缩略图配合编号、尺寸、母板候选、图层及加工侧。行选中表示正在查看，复选框表示参与加工；选中详情提供内／外侧示意及批量修改，多选混合加工侧会明确提示。「全部／加工顺序」只切换查看范围，有效刀路顺序不可拖动修改；结果失效后返回全部轮廓。
- 一份图纸包含多个独立母板时，生成结果会自动进入多母板模式并合并预览；点击画布中的母板外框或加工摘要中的母板项，可加载该板独立 NC、查看代码并播放轨迹，点击「查看全部母板」可返回全图静态预览。点击「导出多个 NC」会按母板分组，在默认 NC 目录生成 `图纸名_01.nc`、`图纸名_02.nc` 等文件。每块板独立使用母板左下角原点并单独校验；同一母板内的多个零件仍合并在一个程序中。母板重叠、轮廓跨板或轮廓未归属时会拒绝整批写出。
- 独立的 1220 × 2745 mm 标准矩形母板逐块识别，支持旋转及 ±0.01 mm 尺寸误差；只有一个零件或没有零件的母板也可识别，被其他轮廓包含的矩形不会因此自动成为母板。同图层闭环若仅因冗余顶点或浮点噪声被重复提取，导入时自动合并并提示保留的轮廓编号；原始加工几何与真实间隙检查保留。
- 中央画布：保留深色 CAD 视图、鼠标位置缩放、中键平移、定位及适应全图；画布边缘的「原图／成品边／刀心／空移／方向」图例可直接切换显示。空移连线来自生成的实际 NC，包含分层返回与结束停车，适应全图包含停车位置。大 CAD 坐标转换为局部坐标绘制。参数改变后，旧成品边、刀路与方向淡化，显示「上次结果 · 待更新」；旧结果不可导出、复制或播放。
- 播放控制：播放/暂停、回到起点、进度定位及 `0.25× / 0.5× / 1× / 2× / 5× / 10×` 倍率（默认 `10×`）；播放栏单行显示实际刀次、路径、加工层和 NC 行，XYZ 位于底部状态栏。时间为估算，空移采用 `10000 mm/min` 示意速度。
- 参数侧栏：常用参数区突出「留皮厚度」，其余「机床与工件／刀具／切削／深度与分层／补偿与方向／机床输出与结束动作」分组默认收起。机床、板厚、Z 基准、母板或手动原点均可设置；深度组显示板面 Z、绝对目标 Z、切入量、实际有效层数和高出板面的安全距离，并提供稳定顺序、分层与斜坡设置。参数错误会展开对应分组并定位首个错误。保留「H 跟随刀号」；参数导入、导出、保存启动默认和恢复所选机床内置值放在「设置」。
- 结果抽屉：收起时中央底部保留「加工摘要／NC 代码／诊断」入口，展开只占中央列，左右侧栏保持全高。默认高度占中央可用区域的 28%，可调整为 22%–55%；「大视图」用于阅读长源码和诊断，再点「返回预览」恢复。无警告的成功结果和仅 Information 信息保持收起；Warning 或 Error 自动打开诊断，Warning 仍可导出 NC。
- ≥1200 DIP 同时显示轮廓、画布和参数；900–1199 DIP 显示画布与上次使用的一个侧栏；<900 DIP 通过唯一选中的「预览 / 轮廓 / 参数 / 结果」切换。首次默认侧栏宽度为左 240、右 320 DIP，已有合法设置继续沿用。侧栏可收起、调整宽度，并从画布工具栏重新打开。
- 说明：未打开文件也能阅读刀具补偿、刀径、转速进给、深度、安全高度、原点与控制器适配；当前任务附带实际参数及返回修改入口。页面没有检查进度或确认操作。
- 设置：整页滚动卡片包含外观、文件保存、参数配置和关于。原生 Fluent 外观可跟随系统，或选择浅色、深色；画布保持深色。

## 加工规则

首次默认选中「宝元 LNC · 当前木工开料机」：板底／垫板上表面 Z0、板厚 17 mm、`T2 / H2`、6 mm 直刀、`M03 S18000`、切削进给 `10000 mm/min`、移至板面进给 `8000 mm/min`、斜下刀进给 `3000 mm/min`、目标 `Z-0.10`、安全 `Z45`、逆时针。默认启用「优先保持零件稳定」：按内孔、普通外轮廓、母板/外框候选排序，并在每个深度层依次加工全部路线。稳定优先只影响加工顺序，不会隐式开启深度分层。默认留皮为 0、关闭分层，只加工一次最终深度；留皮大于 0 时先加工到板底上方的留皮高度，再加工到最终深度，共两次。留皮为 0 且显式开启分层时，才按配置的最大层深生成中间层。斜坡沿补偿后的闭环走 80 mm，到目标层后完整再走一圈；短轮廓允许跨越闭合点继续绕行。

外侧零件成品边内缩 1 mm，内侧孔成品边外扩 1 mm，再进行刀具半径补偿。默认外侧直线段刀心相对原图净外偏 2 mm。板底为 Z0 时，`Z-0.10` 表示切穿后再下切 0.10 mm；17 mm 板面为 Z17，Z45 高出板面 28 mm。安全 Z 必须高于板面，启用结束停车时停车 Z 不得低于安全 Z。默认只有 `-0.10` 一个深度层。留皮为 0、显式开启 3 mm 分层时，层位才是 `14、11、8、5、2、-0.10`；例如留皮 0.3 mm 时则为 `0.30、-0.10` 两次加工。

保留 0.01 mm 拼接、闭环识别、冲突检查、路径方向与两步补偿。稳定模式为逐层跨轮廓加工，并根据其它成品边和可信母板边界确定性选择较安全的下刀点；关闭后保留逐轮廓完成全部深度的传统顺序。曲线按毫米误差自适应离散，上限 0.05 mm；内部采样进一步限制到 0.01 mm，避免大圆弧粗折线引发虚假的窄槽诊断。真实窄槽、分裂、坍塌、间隙不足仍拒绝生成。

稳定顺序只降低零件过早切断后移动的风险，不模拟材料、真空、压板、夹具、桥位或底部薄皮，也不保证现场固定。相关诊断是允许导出的警告；正式加工仍必须核对装夹、材料状态、控制器仿真与空跑结果。

宝元默认以**指定母板左下角**为 G54 X0 Y0。唯一明确的轴向矩形母板候选可自动选定；无母板或有多个候选时需指定母板或切换手动原点。母板不随加工勾选变化，刀路外扩产生的负坐标保留。刀径补偿始终由软件预先计算；宝元 LNC 的现场格式不输出 G40，通用 Fanuc 旧版保留 G40，任何模式都不能再叠加 G41/G42。机床输出可配置单独 T／T+M06、程序外框、停车点及末尾 M17；宝元默认单独 T、抬至 Z50 后移到 X200 Y2600、M17/M30。M17 的实际动作不在预览中模拟。

「通用 Fanuc · 旧版」保留旧版板面 Z0、安全 Z5、垂直分层下刀和刀心包围框左下角原点，保留 `%` / O 程序号及 M06。输出禁止覆盖源 CAD，文件通过同目录临时文件原子替换。

## 任务与数据

| 操作 | 用途 | 文件 |
| --- | --- | --- |
| 保存任务 | 下次继续编辑这份图纸的加工设置与轮廓选择 | `.cad2nc.json` |
| 设置 → 导出当前参数 | 在另一任务或电脑上复用刀具和工艺参数 | `.cad2nc.config.json` |
| 导出 NC | 输出本次有效生成结果 | `.nc` |

加工任务保存源图纸相对引用／哈希、参数、母板引用与手动原点、几何标识、加工选择和兼容用视图字段，不保存有效 NC。重新打开会重新导入，恢复任务参数、原点与轮廓选择，并沿用本机最后的面板布局；视口会自动适应新图。源图变化时重置选择与原点，缺失时提供重新定位；传给另一台电脑时需同时带上源图纸。

首次「保存任务」直接使用 Windows 实际「文档」位置下的 `CAD2NC\任务\图纸名.cad2nc.json`，已有任务继续保存到原任务文件；「导出 NC」默认写入 `CAD2NC\NC\图纸名.nc`，目录在首次写入时自动创建。新任务或 NC 同名时可选择覆盖、另存为或取消。更多菜单保留「加工任务另存为…」和「机床程序另存为…」。任务与配置选择器使用 `.json` 过滤器，返回后统一补齐各自后缀，覆盖确认针对最终路径。保存成功显示完整路径并提供「打开文件夹」。

「设置 → 文件保存」可分别选择、打开或恢复两个默认目录，显示完整路径，变更立即持久化。改变默认目录不会移动已有文件，临时另存为不会更改默认设置。目录不可写或保存失败时，当前页显示原因，可重新选择位置。

启动使用已保存的启动默认配置，未保存过时使用宝元内置值。普通任务内的编辑不会自动覆盖启动默认；在设置中选择「保存当前参数为启动默认」才保存。恢复内置值按当前所选机床执行。打开任务使用任务参数快照；同窗打开另一张 CAD 沿用当前工艺但清除上一张图的母板与手动原点。导入参数先比较再应用并可撤销；导入、恢复、原点或工艺变更后需要重新生成刀路。手工修改 H 会关闭跟随，重新勾选将 H 同步为 T。

新任务与参数配置只写版本 3；版本 1/2 仍可读取，缺少稳定顺序字段时明确迁移为开启。打开旧任务会提示重新生成核对并标记为未保存，但不会改写原任务或已有 `.nc`；保存任务后写为版本 3。母板引用与手动 CAD 原点只属于当前任务，不进入可复用参数文件或启动默认。`settings-v2.json` 保持版本 2，缺少新字段时默认开启，显式关闭可往返保存。

设置和最近任务保存在 `%LOCALAPPDATA%/CAD2NC/settings-v2.json`。兼容旧设置与任务格式；旧个人配置数据继续保留和读取，不再提供配置列表或管理界面，也不自动应用。

后台导入和生成使用快照及版本检查。编辑参数、导入参数、恢复默认、改变加工选择、撤销／重做或重新生成都会清空旧播放，使旧生成结果失效；有效的新结果生成后即可输出。缩放、平移、查看轮廓、切换页面、调整侧栏或结果抽屉、主题与目录调整不会使结果失效，也不会令任务变为未保存。面板布局保存在本机设置中，打开旧任务也继续使用当前软件主题和布局。计算结束时若正在说明或设置页，不会强制跳回工作台。

播放无需先导出 NC。拖动进度会暂停，松开后保持暂停；播放结束停在末尾，再次播放从头开始。二维播放显示编程轨迹，不模拟材料切除、机床偏置表、夹具碰撞或加减速。

## 打开已有 NC

NC 文件在同一工作台进入只读阅读模式，默认打开「NC 代码」。宽度 ≥900 DIP 时，轨迹与程序详情并排；详情可切换「程序参数／NC 代码／解析提示／加工摘要」，也可放大或收起。详情宽度单独保存在本机，默认 480 DIP，不覆盖 CAD 侧栏偏好；不足 900 DIP 时使用「预览／程序详情」切换。无法播放的程序优先显示源码大视图。此模式隐藏加工编辑、刀路生成、任务保存与生成程序导出，设置中的参数操作禁用，不改变当前加工参数。

可复制完整原文；可播放程序支持点击代码行暂停并定位运动，播放行与轨迹、XYZ 同步。带来源行的解析提示提供「定位源码行」，跳转到相应原文；没有来源行的提示不提供跳转。

程序参数列出程序号、T／H、S／F、主轴方向、单位、坐标模式和可计算的 XYZ 范围；多个值附来源行。刀径、材料、留量与实际安全高度无法从程序确定时显示「未提供」，不套用软件默认参数。未提供 Z 时显示「Z 未指定」，未知起点不按零点绘制。

支持 G0／G1 和 G17 平面的 G2／G3，包括 I／J、正负 R、圆心形式整圆和带 Z 的螺旋；支持 G20／G21、G90／G91、G90.1／G91.1、G94。未声明时按毫米、XY 平面、绝对终点、相对圆心和每分钟进给解释，并在解析提示中标明。圆心模式与终点模式独立。可查看单一 G54–G59 工件坐标系中的编程轨迹。

外部 NC 可查看带 `G91 G28 Z0` 等回参考点指令的旧程序：仅接受 G91 模式下显式指定轴且位移全为零的 G28，不绘制机床回零运动，也不计入其时间；回零轴的位置标为未知，后续绝对坐标重新建立位置，未知起点的移动不绘制。末尾独立的 `M17` 仅在其后直接以独立 `M2/M30` 结束时接受（可有 N 行号，块间可有注释、空行或 `%`）；保留原文并提示其功能由控制器定义，不模拟相应动作或时间。以上提示附原始行号，不修改输入 NC，也不改变 CAD2NC 生成的程序格式。

宏、子程序、固定循环、其它圆弧平面、刀径补偿、其它机床坐标移动、超出上述形式的 G28/M17，或运动中切换工件坐标系等超出范围时，保留原文与可识别参数，提示具体行并禁用整份轨迹播放。后台读取和解析可取消；外部 NC 上限为 32 MiB、100 万行及 100 万运动块，超限会明确报错。读取失败保留此前打开的内容，解析问题仍可查看源码。

## 构建

Windows x64、PowerShell 7，安装 `global.json` 指定的 .NET SDK 10.0.400。SDK 风格 WinUI 项目使用 NuGet 中的 XAML 编译工具，NuGet 锁文件已提交。首次构建先准备经过校验的固定版本 Inno Setup 7.1.0 便携编译器：

```powershell
.\scripts\prepare_inno.ps1
.\build.ps1
```

脚本执行锁定依赖还原、C# 回归测试、.NET/Windows App SDK 自包含发布，收集许可并用发布 EXE 转换测试图纸，然后生成安装包和 `dist/CAD2NC-source.zip` 对应源码。前次目录移入 `build/previous-release-*` 保留。需要便携 ZIP 时运行 `.\build.ps1 -PortableZip`；便携目录仍须整体保留。

图标原图及多尺寸资源位于 `src/Cad2Nc.App/Assets`；`scripts/prepare_icons.ps1` 可从源图重新生成图标，无需图像服务或 Python。版本唯一来源为 `Directory.Build.props` 中的 `Version`；程序集、Windows 应用清单、安装包和 CLI 摘要均从它派生。

除系统安装的 SDK 外，也可通过 `python scripts/prepare_dotnet.py` 下载并验证官方 SDK 到 `.tools/dotnet`，此脚本仅用于开发机准备，发布程序不依赖 Python。受限开发环境的 NuGet HTTPS 传输问题可用 `scripts/nuget_bridge.py` 提供仅绑定回环地址的开发代理；正常构建直接使用官方 NuGet。

```powershell
# 仅测试
 dotnet test tests/Cad2Nc.Tests/Cad2Nc.Tests.csproj
# 控制台转换入口：默认宝元配置，图纸须有唯一明确的矩形母板
 dotnet run --project src/Cad2Nc.Cli -- --convert "D:\图纸\板件.dwg" --output "D:\加工\板件.nc" --summary "D:\加工\摘要.json" --accept-import-diagnostics
# 无母板图纸：明确指定 CAD 中对应 G54 X0/Y0 的位置
 dotnet run --project src/Cad2Nc.Cli -- --convert "D:\图纸\零件.dxf" --output "D:\加工\零件.nc" --origin manual --origin-x 1000 --origin-y 2000 --accept-import-diagnostics
```

CLI 默认使用宝元内置值，不读取桌面应用保存的启动默认。使用 `--config "D:\工艺\宝元.cad2nc.config.json"` 复用导出的参数，或用 `--profile legacy` 选择旧版；`--config` 与 `--profile` 不能同时指定。`--origin sheet|manual|toolpath` 可覆盖原点方式；母板原点可用 `--sheet-contour C0001` 指定，手动原点须同时提供 X、Y。

`--include-outer` 将母板候选加入加工选择，但在 `sheet` 原点模式下，作为原点基准的指定母板仍会被排除，不能用这个开关加工它。`--accept-converter-diagnostics` 保留为诊断确认的兼容别名；无单位图纸需核对后使用 `--assume-mm`。

推送与应用版本一致的稳定版 tag（当前为 `v2.7.0`）后，GitHub Actions 会在构建、测试和依赖审计全部通过后自动发布 Release，提供安装 EXE、对应源码 ZIP 和 SHA-256 校验文件。修复递增修订号，兼容的新功能递增次版本，不兼容的改动递增主版本；已发布的 tag 和下载文件不覆盖。分支 push 和 pull request 只做检查。版本规则、发布命令及草稿重跑方式见 [开发与发布检查](docs/DEVELOPMENT.md)。普通构建通过不代表依赖审计或独立机器验收通过。

| 路径 | 职责 |
| --- | --- |
| `src/Cad2Nc.Core` | 不可变模型、实体展开、轮廓提取、几何规划、NC 生成与播放解析、原子写入 |
